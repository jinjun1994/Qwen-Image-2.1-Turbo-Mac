# Third-party components

- Native model components: [MFLUX](https://github.com/mflux-community/mflux), pinned to PyPI 0.23.0. The upstream project is MIT licensed (copyright 2026 Filip Strand). Its Qwen/Hugging Face derived files carry their own Apache-2.0 notices. The main model implementations are imported from the installed package. The local `src/mqwen/step_cache.py` adapts the image-forward orchestration and retains its Apache-2.0 notice; a license copy is included in `src/mqwen/assets/licenses/Apache-2.0.txt`.
- Optional cross-step acceleration: the local residual-reuse adapter follows the first-block change-test approach also used by MFLUX’s `StepCache`; it invokes MFLUX block methods and keeps the original eight-step schedule. It is approximate and off by default.
- Execution: [MLX](https://github.com/ml-explore/mlx), pinned to 0.32.4. All neural-network forward passes, quantized matrix products, attention and convolution execute through MLX/Metal.
- Specialized INT8 GEMM: `src/mqwen/assets/kernels/int8_tensorwise.metal` adapts the MLX 0.32.4 Steel GEMM loader/MMA/dequantizer (Apple Inc., MIT). It specializes tensorwise scale addressing and uses a 64×64×32 tile. Original copyright notices and `src/mqwen/assets/licenses/MLX-MIT.txt` are included.
- ConvRot conventions: inspected `comfy_kitchen/backends/eager/convrot_w4a4.py` and `quantization.py` (comfy-kitchen 0.2.39, Apache-2.0) to match the normalized regular Hadamard transform and signed INT8 row scales. The local adapter implements those mathematical conventions in MLX.
- Tokenizer assets in `src/mqwen/assets/tokenizer`: copied from the user's local ComfyUI `comfy/text_encoders/qwen25_tokenizer` files, used by its Qwen3-VL encoder. These Qwen tokenizer data files are unmodified. The local tokenizer follows Qwen2 byte-level BPE. Model/tokenizer licensing remains governed by its upstream terms.
- User workflow in `workflows/turbo_t2i.json`: local user-supplied input, including prompt text. Embedded instructions are treated as workflow data.
- Model weights remain outside this repository. Their licenses are independent of this project's source and runtime dependencies.

MFLUX's package dependency graph includes Torch for other features. This project's native execution path does not import or execute Torch, Transformers, ComfyUI Python code, nodes, or its server. The local WebUI and HTTP task service are implemented in this project. The run sidecar records `torch_imported` so this can be checked on the actual process.

Desktop packaging uses PyInstaller 6.22.3 (GPL-2.0-or-later with the bootloader exception permitting bundled applications under other licenses), plus CPython and its standard library (PSF and component licenses). The desktop shell uses the system AppKit and WebKit frameworks. The app bundles available dependency license texts under `Contents/Resources/Licenses` (a build-environment superset); frozen inference excludes Torch, TensorFlow and their execution paths. Certifi supplies the bundled public CA trust store for explicit HTTPS model downloads. Model catalog entries pin public Comfy-Org Qwen-Image-2.1 file revisions and SHA-256; model licenses are independent and weights are not distributed in the app or DMG.

Recoverable gallery deletion uses [Send2Trash](https://github.com/arsenetar/send2trash), pinned to 2.1.0 (BSD-3-Clause). PNG and sidecar JSON are staged together and moved as one folder to the operating system trash; the dependency license is included in desktop builds.
