模型与本地服务

先关闭推理服务再修改模型路径。已有 ComfyUI 模型可以直接复用，不会复制。首次使用建议从 512 × 512、标准 8 步开始。

从公开源下载模型

完整权重约 17.3 GB，另需转换缓存与运行内存。下载会连接所选公开源；提示词及图像留在本机。模型须遵守发布者许可。

修改目录后先保存设置。下载完成后点击“使用已下载模型”，保存并启动推理服务。

默认填入内置目录中同一文件的校验值；其他文件需填写发布者的准确值，兼容性由引擎加载检查。

生图 API 接口

与当前 WebUI 共用单任务常驻引擎，仅监听本机。桌面窗口顶部可启停整个 HTTP 服务并更改端口；关闭推理服务只释放模型。

GET /api/state 查询进度和 image_url；POST /api/cancel 取消；POST /api/engine/start 或 /stop 控制模型。所有 POST 使用 application/json。
