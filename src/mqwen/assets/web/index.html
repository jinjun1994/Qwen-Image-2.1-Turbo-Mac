Image-generation API

The API shares this WebUI's single-job resident engine and listens only on localhost. The desktop toolbar controls HTTP and its port; stopping inference only releases models.

GET /api/state for progress and image_url; POST /api/cancel to cancel; POST /api/engine/start or /stop to control models. All POST requests use application/json.
